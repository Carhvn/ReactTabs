# React Tabs

Небольшое приложение на React для просмотра пользователей, постов и комментариев из JSONPlaceholder API.

## Функциональность

- приветственная страница с переходом на `/content`;
- переключение вкладок «Пользователи», «Посты» и «Комментарии»;
- загрузка данных через нативный `fetch`;
- отображение состояния загрузки и ошибок;
- просмотр данных пользователей;
- просмотр постов;
- загрузка комментариев выбранного поста;
- скрытие комментариев при повторном нажатии;
- просмотр общего списка комментариев.

## Реализация

- приложение полностью перенесено на TypeScript;
- общая логика запросов вынесена в кастомный хук `useFetch<T>`;
- состояния запросов отображаются через компонент `RequestStatus`;
- данные API типизированы интерфейсами `User`, `Post` и `Comment`;
- приложение разделено на страницы и переиспользуемые компоненты.

## Технологии

- React 18;
- TypeScript;
- Vite;
- React Router;
- CSS;
- JSONPlaceholder API.

## Запуск проекта

Склонировать репозиторий:

```bash
git clone https://github.com/Leeps123124/ReactTabs.git
```

Перейти в папку проекта:

```bash
cd ReactTabs
```

Установить зависимости:

```bash
npm install
```

Запустить приложение в режиме разработки:

```bash
npm run dev
```

После запуска открыть адрес, который Vite покажет в терминале.

## Проверка проекта

Проверить типы:

```bash
npm run typecheck
```

Запустить линтер:

```bash
npm run lint
```

Создать production-сборку:

```bash
npm run build
```

Локально открыть production-сборку:

```bash
npm run preview
```

## API

Данные загружаются из [JSONPlaceholder](https://jsonplaceholder.typicode.com/).
