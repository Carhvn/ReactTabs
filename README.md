# React Tabs

Небольшое React-приложение для просмотра пользователей, постов и комментариев с использованием JSONPlaceholder API.

## Функциональность

- приветственная страница;
- переход на страницу `/content`;
- переключение вкладок «Пользователи», «Посты» и «Комментарии»;
- загрузка данных через нативный `fetch`;
- отображение состояния загрузки и ошибок;
- просмотр пользователей;
- просмотр постов;
- загрузка комментариев конкретного поста;
- скрытие комментариев при повторном клике;
- просмотр общего списка комментариев.

## Возможные улучшения

Логика `fetch`, загрузки и обработки ошибок повторяется в нескольких компонентах. В дальнейшем её можно вынести в отдельный кастомный хук `useFetch`, чтобы не писать одинаковый код для каждого запроса.

## Использованные технологии

- React;
- Vite;
- React Router;
- JavaScript;
- CSS;
- JSONPlaceholder API.

## Запуск проекта

Склонировать репозиторий:

```bash
git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ
```

Перейти в папку проекта:

```bash
cd ReactTabs
```

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

После запуска открыть адрес, который Vite покажет в терминале.

## Production-сборка

Создать production-сборку:

```bash
npm run build
```

Локально проверить готовую сборку:

```bash
npm run preview
```
